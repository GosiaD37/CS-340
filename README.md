1. How do you write programs that are maintainable, readable, and adaptable?

Writing maintainable, readable, and adaptable programs is a priority for me as a developer. I focus on modular design, breaking functionality into smaller, reusable components. In Project One, I developed a CRUD Python module to handle database operations, isolating database interactions from the rest of the application. This made future updates easier without disrupting the entire program. I also follow consistent naming conventions and coding standards to ensure the code is easy to understand and maintain. Clear documentation and inline comments help explain the purpose of functions and variables, making the code more accessible. I design programs with scalability in mind; for example, the CRUD module can handle additional fields or data types if the database evolves. Separating database logic from user interface logic made it easier to integrate the module with the dashboard widgets in Project Two, allowing the dashboard to focus on user interaction while the module handled data access. This approach offered key advantages. The CRUD module streamlined connecting the dashboard to the MongoDB database, reducing redundant queries and saving time. It’s also reusable for future projects, whether for different databases or applications, improving efficiency and ensuring adaptability to meet evolving client needs.

2. How do you approach a problem as a computer scientist?
   
As a computer scientist, I tackle problems methodically by breaking them into smaller, manageable tasks. For the Grazioso Salvare project, I started by carefully analyzing the requirements for the database and dashboard. The client needed a system to store rescue dog data and a dashboard to visualize and filter this information. My first step was to design a database schema that could handle the necessary queries and visualizations. Then, I developed the CRUD Python module to manage data operations, creating a clear and efficient connection between the database and the dashboard. This project required integrating multiple components, including the database, backend logic, and user interface, which made it more complex than previous assignments. I handled this by working incrementally, beginning with database queries and testing them thoroughly before incorporating them into the CRUD module. Once the module was functional, I focused on integrating it with dashboard elements like the data table and pie chart, testing each widget separately to ensure seamless functionality. This step-by-step approach helped reduce complexity and simplify debugging. For future projects, I plan to continue breaking down problems into smaller tasks and testing each component individually before integrating them. Additionally, I would incorporate tools like flowcharts and database diagrams early in the planning phase to better understand client requirements and ensure my solutions align with their objectives.

3. What do computer scientists do, and why does it matter?

Computer scientists address complex challenges by creating, improving, and optimizing algorithms, systems, and software. Their work drives efficiency and innovation across industries. In the Grazioso Salvare project, my role involved developing a database and dashboard to simplify the process of identifying rescue dogs suitable for training. By delivering an intuitive and interactive dashboard, I helped the client analyze data more effectively, enabling faster and more informed decision-making while improving overall operational efficiency. This project highlights how computer scientists transform raw data into meaningful insights. My work allowed Grazioso Salvare to utilize their data efficiently, minimizing the time required to filter and select the right dogs for rescue training. This not only conserves resources but also advances their mission of saving lives through search-and-rescue efforts. On a broader scale, computer scientists play a vital role in building tools and technologies that enable organizations to meet their objectives. By leveraging skills in data management, software development, and user-focused design, we provide businesses like Grazioso Salvare with reliable, scalable solutions, allowing them to concentrate on their core missions.
